## 2. 控制面组件与部署形态

当前仓库提供本地代码、CI 检查和部分容器构建定义，不提供完整生产部署拓扑、IaC、编排或 CD。以下目标形态均为规划，不表示已部署。

| 组件 | 当前依据 | 目标部署形态 | 状态 |
| --- | --- | --- | --- |
| Laravel PHP API (`apps/php-api`) | 当前本地 MVP 后端；本地使用 SQLite。`docker/Dockerfile.php` 构建 PHP 8.4 CLI 镜像，入口为 `artisan serve`，使用 SQLite 扩展。 | 受控 PHP 应用运行环境；生产前选定正式数据库与迁移/备份恢复策略。镜像入口须经生产架构评审，不能仅凭存在 Dockerfile 即认定适合公网生产。 | 本地实现/CI 覆盖有限；生产拓扑待定。 |
| Node API (`apps/api`) | Express/TypeScript API，`start` 运行 `dist/index.js`；README 标记为旧 Node API/legacy。本地当前 Web 代理 Laravel。 | 先确定是否继续作为独立服务及其职责；若保留，补齐服务隔离、生产配置、健康检查、持久化和发布定义。 | 有代码和 CI build/test；无生产 Dockerfile 或部署定义。 |
| Web (`apps/web`) | `docker/Dockerfile.web` 用 Node 22 构建静态站点并以 Nginx 1.27 Alpine 提供静态文件；本地使用 Vite。 | 静态制品发布至 Web 托管/源站；经评审可置于 CDN 前。API 反向代理与跨域/安全策略按环境配置。 | 镜像构建已定义；生产发布/路由未验收。 |
| 队列与调度 | 本地可运行 Laravel scheduler；云端回收/队列能力不能由本机调度代替。文档记载生产常驻 worker、告警和故障接管未部署。 | 在受控环境部署常驻 scheduler 与 queue worker；定义幂等、重试、死信/失败任务处理、心跳、积压与失败告警。 | 规划中；无已验收生产 worker。 |
| 数据库 | Laravel 演示使用 SQLite；本地演示库与旧 Node 演示库分离。 | 生产/预发布采用独立托管数据库或经审查的高可用数据库；每环境独立身份、备份、恢复演练、迁移窗口与保留策略。 | 生产数据库未选定/未验收。 |
| 缓存 | 当前资料未证明已部署共享缓存。 | 依据会话、限流、队列和缓存需求选择受控服务；明确 TTL、失效与故障行为，不将缓存作为唯一事实来源。 | 规划中，产品与容量需求待定。 |

不要将本地 SQLite、单 API 进程或演示种子数据直接复制为生产架构。生产数据库迁移采用向前兼容的 expand/contract，并先验证备份可恢复；涉及账务或权益事实时不得盲目回滚数据。

## 3. 数据面 node-agent 与隔离节点

`apps/node-agent` 当前包含 Go peer store、TLS 1.3/HTTP2 数据面、mTLS 管理 API、容量限制、设备 proof、撤权与最终测试回执等离线核心。命令只允许 `NODE_AGENT_MODE=isolated-test`；生产模式不可启动，`confirmed_test` 回执不代表会员节点确认。它不配置生产 Mihomo、WireGuard 或 TUN，也不生成会员 profile。

隔离测试部署要求：

1. 使用专用短时节点和实验身份，核对变更授权、资源标签、账号/区域、TTL、成本边界及回收角色；不得把受保护的控制面主机纳入节点回收。
2. Agent 只按隔离测试配置运行，管理监听保持 loopback；按 runbook 经 SSM/受控转发访问，不开放未批准的公网管理入口。
3. 部署包固定 SHA-256；临时测试证书和私钥通过批准的秘密传递方式提供，测试完成后按计划销毁并核对实例、盘、网卡、安全组、调度任务等残留。
4. 测试节点不进入生产线路、不签发会员凭证、不承载会员流量。普通 Clash/Mihomo 导入不构成 proof-capable 设备验收。

生产 node-agent 当前**不可部署**。必须先完成生产 wire contract、Laravel bind/rotate/revoke outbox 与持久回执、生产证书生命周期与可信密钥存储、健康/指标/审计、恢复与部署哈希校验，并通过 M6 云端真实验收。设备限制不得放宽；到期立即拒绝新连接/续租，但只有节点返回撤权回执后才能声明现有连接已断流，并核对最终累计流量。

## 4. 域名、TLS 与证书

- 控制面 HTTPS：规划为每个环境独立配置域名与 TLS 证书，终止位置（负载均衡器、反向代理或 Web 源站）和内部加密边界待架构决策。域名、DNS、证书签发/续期责任人均为待配置；本文不含实际域名或地址。
- 节点 mTLS：与控制面公网 TLS 分开管理。测试 CA/证书只用于隔离实验；生产 CA、服务端/客户端证书、节点身份绑定、签发/轮换/撤销和私钥保护均是外部输入及放行前置条件，不得复用测试材料。
- 证书与私钥不得提交到仓库、镜像层、普通日志、工单或部署命令参数。配置中仅存秘密引用，运行时从批准的秘密渠道注入；生产签发保持关闭，直到完整验收与审批通过。
- 证书校验必须验证身份、用途、有效期与链；失败时 fail closed。轮换和吊销要有审计、重试和旧证书失效确认。

## 5. CDN 边界

CDN 仅用于安装包与 Web 静态资源（HTML/CSS/JS/图片等）的缓存和分发；缓存策略、版本化文件名、回源权限和发布失效流程需按环境配置。认证 API、会员订阅秘密、管理接口和节点管理 API 不得作为公开静态缓存对象。

CDN **不是 VPN 数据通道**，不承载任意 VPN TCP/UDP 隧道，也不替代节点入口、调度或用户级授权。控制面网站/API 的 HTTPS 负载均衡与 VPN 数据面节点流量分别设计、验收和监控。

## 6. 发布流水线与回滚

已加入的 [CI workflow](../.github/workflows/ci.yml) 在 push/PR 上执行 Web build、Node API TypeScript build、Node API tests 和 Laravel tests，并从仓库根目录构建 PHP 与 Web 容器镜像。根目录 `.dockerignore` 排除所有层级的 `.env`/`.env.*`、Composer/npm/netrc 凭据文件、AWS/SSH 私有配置、密钥库和私钥格式、依赖、构建产物、SQLite 数据库、Laravel runtime storage/cache 与 `ops/.state`；10 个 Docker 隔离夹具确认相关本地输入不可被 `COPY` 读取。PHP Composer vendor stage 安装 `unzip` 后，hosted CI `45259345222` 的 PHP/Web 镜像构建成功。本机 Docker Hub 拉取官方基础镜像仍返回 OCI config descriptor 错误。CI 没有部署步骤、制品发布、环境审批、镜像推送或生产密钥注入。它是 CI，不是 CD。

现有容器定义：

- [PHP Dockerfile](../docker/Dockerfile.php)：PHP 8.4 CLI、多阶段安装 Composer 依赖、以 `www-data` 用户运行 `php artisan serve`，端口 8000。
- [Web Dockerfile](../docker/Dockerfile.web)：Node 22 构建 Web 静态资源，Nginx 1.27 Alpine 提供静态文件，端口 80。
- 当前没有 `apps/api` 或 `apps/node-agent` 的 Dockerfile；也没有完整 compose/Kubernetes/云端部署流水线。不要把 CI 镜像定义描述成已上线部署方案。

规划中的交付流水线：审查合并 → CI 静态检查/测试/构建 → 生成不可变制品和 SBOM/摘要 → 登记制品 → 部署 staging → 冒烟、迁移兼容、端到端/节点验收 → 人工放行 → 小流量灰度 → 观察 → 扩量。实际 CD 工具、制品仓库、部署平台、审批人和阈值均待决策；不得在门槛未过时接通生产签发或自动部署。

发布/回滚要求：

1. 变更单记录影响范围、维护窗口、负责人、验证、监控、回滚条件与批准人；固定代码版本、镜像 digest、配置与迁移版本。
2. 先在 staging 演练备份恢复、数据库迁移、API/Web 冒烟和节点配置回滚。扩量按既有工程规划逐级进行；任何错误阈值、账务/权益对账差异、数据损坏迹象或容量不足都立即停发。
3. 应用回滚切回已验证不可变制品；Web 静态资源回滚到上一个版本；线路/节点配置回到最后一个已验收版本并保留旧节点容量。
4. 数据库变更采用兼容发布与前向修复；不可假设应用镜像回退可以逆转已提交的权益、支付或账本事实。
5. 节点替换先验收新节点再发布配置，观察后排空旧节点；失败时恢复旧线路/配置。不得通过放宽设备绑定或跳过撤权回执完成切换。

## 7. 可观测性与运维 Runbook

当前生产常驻 worker、告警、故障接管与逾期资源盘点未验收。目标至少包括：API/队列错误率和延迟、worker 心跳/积压/失败、数据库连接与备份、节点容量与健康采样时间、连接成功率/握手延迟/丢包、撤权回执时延与最终流量、证书有效期、部署版本和资源到期清单。未知或陈旧状态显示为未知，不显示健康。

日志与指标应有追踪 ID、环境/服务/版本、脱敏错误码和时间戳；禁止记录口令、私钥、完整订阅 URL、访问令牌或用户流量内容。告警、值班责任人、保留期、仪表板与 SLO 阈值尚待建立，压测建议值须经实测校准后才可成为放行阈值。
