# 多端异常恢复交互稿

> 草稿，待产品确认

本文用于补齐 Windows、macOS 与浏览器扩展的异常提示及恢复路径，供产品、设计和客户端评审。以下文案与动作均为候选稿，不代表产品定稿、能力承诺或上线结论；实际状态须以客户端可观测结果和服务端/节点回执为准。

## 统一原则

- 三端使用相同的状态含义和核心提示；按平台调整操作名称，不改变用户需要完成的恢复步骤。
- 将账号认证、会员权益、设备授权、订阅配置、节点连通性和本机隧道状态分别表达。某一状态正常不代表其他状态正常。
- 只有服务端确认后才提示认证失效、设备授权撤销或订阅到期。网络请求超时、离线缓存或错误响应不能替代确认。
- 没有匹配的节点撤权回执时，不提示“已断流”“已断开”或“设备已限用”。可以说明请求仍在确认中，并提供查看状态或联系支持的入口。
- 不因恢复失败而放宽设备数限制，不自动释放待确认撤权设备占用的名额。
- CDN 只用于静态资源分发，不作为 VPN 数据通道，也不用于判断隧道或节点是否连通。
- 浏览器扩展用于账户/订阅管理，不建立 VPN 隧道；扩展状态不得描述成 VPN 已连接或已断开。

| --- | --- | --- | --- |

## 各端交互细节

### Windows

- 网络恢复后由用户触发重试；不得循环弹窗或因 API 暂时不可达自动切换线路。
- 系统代理、TUN 或驱动权限问题应进入独立的平台权限提示，不混入“断网”提示；本稿未覆盖其逐步系统设置指引。
- 如果本机仍报告隧道活动但节点状态未知，使用“连接状态待确认”，不显示“已断开”或“已断流”。

### macOS

- 网络恢复后由用户触发重试；不得将浏览器资源加载成功当作 VPN 节点恢复。
- Network Extension/System Extension 权限问题应进入独立的平台授权提示；授权状态与会员、订阅状态分开显示。本稿未指定系统设置的逐步路径。
- 如果节点回执缺失，即使已发起本机断开动作，也使用“正在确认连接状态”，不提前显示“已断流”。

### 浏览器扩展

- 扩展只展示登录、设备订阅授权和订阅配置获取状态，不出现 VPN 连接按钮、隧道状态或“已断流”提示。
- 网络恢复后允许用户重试订阅读取；若凭证已失效或设备授权被撤销，按服务端已确认的具体状态显示，不把普通网络错误归类为撤权。
- 若后续产品确认扩展支持自动更新配置，应另行评审更新中的状态、失败回退和用户可见操作；当前草稿不承诺自动更新或无感恢复。

## 待产品确认

- “服务不可达”与“设备离线”的判定条件、重试频率，以及离线缓存状态的有效时间和视觉标识。
- 认证过期后是否保留本机隧道，以及需要重新登录的具体触发条件；客户端无法确认节点状态时的统一辅助文案。
- 设备撤权的用户可见阶段、设备管理入口、重新授权条件，以及展示节点确认中的等待/升级支持路径。设备名额仅在符合既定节点回执条件后释放。
- 会员权益与第三方订阅到期的命名、续费入口、退款/封禁等其他账户状态是否沿用本稿分支。
- 节点健康数据的时效阈值、线路切换规则和“待验证”状态的交互；扩展订阅获取失败与 VPN 节点不可达需保持不同语义。
- Windows/macOS 平台权限拒绝、配置损坏、凭证轮换等未覆盖异常，及三端一致性验收所需的最终状态清单。
